# A 股 AI 链模型

## 用途与边界

`/ai-chain-model` 是一个可手动运行的收盘后研究工具，用于对 A 股 AI 硬件、端侧 AI 和 AI 应用三条链路做候选排序与仓位约束参考。

- 仅使用可追溯的日线结构化数据和版本化的行业分类档案；不使用 LLM 情绪、新闻或人工事件分数。
- 不连接券商、不发送委托、不自动交易，也不构成投资建议或收益承诺。
- 日终评分默认按 20 个交易日口径；走步回测在信号后的下一可交易日开盘成交，并扣除可配置的佣金、卖出税费和滑点。
- 分类池以当前可获得的成分回放历史时，结果会标注为当前分类池的历史表现，存在幸存者偏差，不能解释为无偏行业历史回测。

## 范围

硬件仅包含 AI 需求的直接供给环节：EDA/IP、半导体材料、设备及关键零部件、晶圆制造、AI 芯片/存储/接口、先进封测、网络芯片及光互连、PCB/CCL/铜连接、AI 服务器/ODM/机柜、服务器电源、液冷及热管理。

数据中心运营、电网、变压器、发电和储能等更长周期基础设施不纳入本期股票池。

## 运行方式

在 Web 侧边栏打开“AI 链模型”，点击“运行日终模型”。系统会：

1. 校验版本化分类池和硬件行业档案；
2. 补齐并检查从 2023-07-01 起的日线数据覆盖、成交额字段和最后交易日期；
3. 先判断宽基市场风险闸门，再计算相对强弱、趋势、动量、量能和回撤风险；
4. 对观察池应用更高的入选门槛，并执行单票 15%、AI 总仓位 60%、硬件子组 20%、观察池合计 15%、6–8 只的上限；
5. 保存成功快照；若质量不足或任务失败，保留最近成功快照并将其标为过期。

“运行回测”会提交一个单独的后台任务。第一版不把这两个任务加入日常调度器，避免影响现有 LLM 分析任务。

## API

- `POST /api/v1/ai-chain-model/runs`：提交一次日终评分任务。
- `GET /api/v1/ai-chain-model/runs/{task_id}`：读取任务进度。
- `GET /api/v1/ai-chain-model/latest`：读取最近一次成功快照；无成功快照时返回 404。
- `GET /api/v1/ai-chain-model/history`：分页读取成功快照。
- `POST /api/v1/ai-chain-model/backtests`：提交走步回测。
- `GET /api/v1/ai-chain-model/backtests/{id}`：读取回测指标与调仓证据。
- `GET /api/v1/ai-chain-model/data-coverage`：读取最近快照中的各标的数据质量。

## 数据质量与校准

覆盖率不足、关键价格字段缺失或数据源失败会拒绝生成新的建议。成交额覆盖不足时，模型退回成交量因子并标为降级。概率、收益区间和相对跑赢概率只从评分日之前已经完成的同类观察窗口校准；样本不足时字段保持为空，不会填充伪精确数值。

## 回滚

该功能使用独立路由、表和前端页面。若需停止使用，撤下 `/ai-chain-model` 导航与路由，并停止提交新任务即可；既有 LLM 分析、通用回测、持仓和日常调度不受影响，已有模型快照保留供审计。
